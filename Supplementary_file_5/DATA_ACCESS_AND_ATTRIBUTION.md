# Data Access and Attribution

These materials accompany the identity-consistent perioperative creatinine study
(R2_IDQC_20261113). They contain calculation code and selected aggregate outputs,
not source records or a permission to redistribute restricted data. Users must
obtain the original data directly from the providers and comply with the terms
they accept. Source access is not guaranteed by this package.

- INSPIRE v1.4.2: credentialed PhysioNet access; Korea Credentialed Health Data
  License-1-0-0 and the applicable data agreement. Cite the dataset and associated
  article listed in the manuscript. Dataset DOI: https://doi.org/10.13026/1eay-yc85
  License: https://physionet.org/content/inspire/view-license/1.4.2/
  Agreement: https://physionet.org/content/inspire/view-dua/1.4.2/
- MOVER: provider-managed access and data usage agreement. Obtain the applicable
  agreement from the provider; this package does not replace it or grant access.
  Project: https://mover.ics.uci.edu/index.html
  Download/access information: https://mover.ics.uci.edu/download.html
- VitalDB v1.0.0: CC BY 4.0 with the required attribution. The supportive analysis
  has release-specific definitions and is not a harmonized independent external
  validation. Dataset DOI: https://doi.org/10.13026/czw8-9p62
  License: https://physionet.org/content/vitaldb/view-license/1.0.0/

The manuscript reference list provides the database articles and the PhysioNet
platform citation. No common license for the three source datasets is implied.
The selected aggregate tables implement the study's reporting controls; these
controls are not an institutional or provider approval, or a universal numeric
threshold imposed by all three databases. Patient-level outputs from optional
local reconstruction must remain in an appropriately authorized environment.

The historical DOI https://doi.org/10.5281/zenodo.23204344 preserves an earlier
analysis. It does not archive or independently reproduce the present R2 results.
No new public release or DOI is asserted by this author-review package.
